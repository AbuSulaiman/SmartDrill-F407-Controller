# SmartDrill G431 MOTOR RC1 — 27 أكتوبر 2026

ملف التحميل: `build/SmartDrill_G431_MOTOR_RC1_2026-10-27.hex`.
المعالج STM32G431CBU6 فقط، وليس STM32F407. عنوان FLASH هو 0x08000000.
تظهر G431 MOTOR RC1 عند التشغيل. البناء: `./build.ps1 -EnableMotor`.

هذه نسخة تشغيل مرشحة للفحص، لا اعتماد نهائي لسلامة الآلة أو لاختبار230V.
تم تجميعها والتحقق من ملف التحميل. لم يُجر اختبار عتاد لهذه النسخة بواسطة المساعد.
الاختبارات السابقة على اللوحة كانت لنسخة STABILITY V3، وليست RC1.

## التوصيلات المؤكدة من المستخدم

| الوظيفة | الرجل |
|---|---|
| خرج H11L1، مفتوح المجمع مع سحب إلى3.3V | PA0، حافة هابطة |
| منزلق المقاومة100k، بين3.3V وGND | PA1 / ADC1 channel2 |
| حساس Hall، نبضة واحدة لكل دورة محور المثقب | PA3، حافة صاعدة |
| قيادة الترانزستور ثم MOC3052، HIGH يشغّل | PA5 |
| LED التشغيل / التوقف | PA6 / PA7، HIGH يضيء |
| START / STOP | PB0 / PB1، الكبسة تغلق إلىGND |
| LCD1602 عبر PCF8574 ومواءمة مستويات | PA15 SCL / PB7 SDA |

لا تستخدم PB8 أو PC6. لا تصل5V مباشرة إلى PA0 أو PA3 أو PA1.
تُترك PA13 وPA14 للبرمجة. كشف عنوان LCD تلقائي، لا تغيير للمحوّل المجرب.

## السلوك

- تبدأ اللوحة STOP. يلزم تحرير الكبسات30ms ثم ضغط START30ms؛ STOP له الأولوية.
- يلزم أمر مقاومة غير صفري وخمس دورات تزامن سليمة، بفاصل9..11ms وحداثة أقل من30ms.
- النسبة المعروضة في السطر الأول هي الطلب. O في السطر الثاني هي نسبة القيادة الفعلية.
- البدء عند1% ثم زيادة نقطة واحدة كل20ms حتى الطلب؛ الوصول إلى100% يستغرق نحو ثانيتين.
- انخفاض الطلب يطبق عند التحديث التالي. الوصول إلى الصفر يوقف ولا يعيد التشغيل تلقائيًا.
- النسبة تتحكم في التأخير: 9000 - O*80 ميكروثانية. ليست نسبة القدرة الكهربائية المقاسة.
- عرض نبضة PA5 هو300us. الحافة H11L1 ليست صفر الجهد الدقيق؛ تعويض الإزاحة صفر حاليًا
  ويحتاج قياسًا عند الجهد ودائرة الكشف النهائية. اختبار12V لا يعاير إزاحة230V.
- عرض RPM من نبضة/دورة؛ لا توجد حلقة PI أو تعويض تلقائي للحمل، ولا يعزز البرنامج الخرج
  عند فقدان الحساس. هذه نسخة تحكم بالنسبة مع مراقبة سرعة، وليست منظم RPM مغلق الحلقة.
- يلزم وصول نبضتين صالحتين خلال مهلة البدء3s. بعد المهلة، انقطاع نبضات الحساس لأكثر من2s يوقف.
- حد زيادة السرعة الحالي1000RPM، موروث من إعدادات الاختبار؛ يحتاج اعتمادًا مقابل محور
  المثقب الفعلي وبياناته قبل استخدام المحرك. ليس ضمانًا لعدم تجاوز السرعة المسموحة.
- فقدان التزامن يوقف، وعودة الإشارة لا تعيد التشغيل. يلزم تحرير START ثم ضغطه مجددًا.
- فحص التعليق الأمامي100ms يلغي القيادة من SysTick ومن مقاطعة التزامن.
  Watchdog مستقل نحو2s يعيد التشغيل إلى STOP إذا علق التنفيذ؛ ليس بديلًا لقاطع طوارئ.
- عولج سباق المقاطعة بين STOP ورفع PA5، مع الحفاظ على إيقاف النبضة والمقارنات معًا.
- التشخيص البرمجي لا يستطيع كشف حساس يعطي نبضات كاذبة أو ترياك يقصر بين طرفيه.

## رموز الشاشة

| الرمز | السبب |
|---|---|
| E0 | لا يوجد خطأ مسجل |
| E1 | فقدان/اضطراب التزامن |
| E2 | لم تتكون قراءة Hall خلال البدء، أو انقطع لاحقًا |
| E3 | تجاوز حد السرعة المضبوط |
| E4 | فشل ADC |
| E5 | طلب START عند المقاومة صفر |
| E6 | تأخر الحلقة الرئيسية أكثر من100ms |

تغير * و. مرة في الثانية مؤشر تحديث الواجهة. الضغط على STOP يمسح رمز الخطأ؛
صوّر الخطأ قبل الضغط عليه. START لا يتجاوز سبب العطل إن بقي قائمًا.

## قبول النسخة على الجهد المنخفض

تبقى230V والمحرك مفصولين عن اللوحة. استخدم ترانس12V AC المعزول واللمبة المجربين،
ودائرة كشف الصفر المؤقتة2.2k/2W كما في الاختبار السابق. هذه المقاومة ليست لجهد230V.

1. بعد البرمجة تحقق من شعار MOTOR RC1 ومن STOP، ومن عدم بدء التشغيل عند إبقاء START
   مضغوطًا أثناء Reset. حرره ثم اضغطه. تحقق من STOP ومن عدم العودة عند تحريره وحده.
2. دون نبضاتHall: شغّل عند50%؛ يجب توقف اللمبة بـE2 بعد نحو3s. هذا مقصود.
3. لاختبار الاستمرار، استخدم مولدًا على PA3 بجهد0..3.3V وتردد10Hz (600RPM)،
   بعد فصل خرج الحساس عن PA3 إن كان موصولًا، مع أرضي مولد إلىGND التحكم.
   لا تجمع خرجين على الرجل، ولا توصل أي مجس آخر إلى جهة القدرة مع هذا الأرضي.
4. تحقق من البدء التدريجي، عرض نحو600RPM، واستقرار التشغيل10دقائق عند نسب مختلفة.
5. أوقف نبضاتPA3؛ يجب توقف اللمبة بـE2 بعد نحو2s. أعدها: لا تشغيل دون START جديد.
6. لاختبار E3 على اللمبة فقط، ارفع مولدHall إلى20Hz (1200RPM)؛ يجب توقف القيادة.
   لا تُجر اختبار تجاوز السرعة بمحرك فعلي. اخفض التردد قبل إعادة التشغيل.
7. افتح فرع AC لكشف الصفر فقط مع إبقاء قدرة اللمبة: يجب STOP/E1، وعدم العودة تلقائيًا.
8. أعد اختبار STOP بينما تضغط START، وعند فقدان التغذية ثم عودتها: تظل الأولوية للتوقف.

لا تُوصل المحرك قبل نجاح هذه الاختبارات ومراجعة عزل اللوحة ومسارات التيار والفيوز
والتأريض والحماية الحرارية وفصل الطوارئ المستقل. برنامج STOP لا يفصل الشبكة كهربائيًا.
